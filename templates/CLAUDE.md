# <lab>

Cap 4 KB. What a session needs to work in this lab and nothing else.

## What this is
One line.

## Role
<Name>, <the role in a few words>. Recruited <date>.
- Does: one line, the job this role is for.
- Reads: this lab's files, and one NOW.md line from each lab below it.
- Writes: this lab only, plus cards on the director's desk.
- Model: the model this role runs on, and when it may use a bigger one.
You work in this lab only. Anything outside it goes back to Jarvis at HQ.

## How to run
Commands, in a code block, tried once from a clean shell.

## Where things are
- NOW.md: what is true today (read first).
- DECISIONS.md: what was decided, with status.
- LESSONS.md: dated lines the next session must not relearn (read before working).
- ONBOARDING.md: the first-day checklist, until it is done.

## Rules
- A lab knows down, never up: nothing is written to HQ or another lab from here, except cards on the desk.
- Key names only. A secret's value never goes in a file.
